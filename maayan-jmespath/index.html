JMESPath — query & reshape JSON, live

JMESPath is a query language for JSON. You write a small expression; it walks the document and returns exactly the piece you want — a value, a filtered list, or a whole new shape. It's what powers aws --query, az --query, and countless JSON scripts. Everything below runs live — edit the JSON or the query and watch the result update. Click any example to load it.

Where you'll actually meet JMESPath

AWS CLI — every command takes --query: aws ec2 describe-instances --query "Reservations[].Instances[].InstanceId" pulls just the IDs out of a huge response.

Azure CLI — same --query flag, same language.

Scripts & automation — the jp CLI, or the library in Python/JS/Go, to extract a field from any JSON API response without hand-writing loops.

Ansible — the json_query filter is JMESPath.

The point: instead of looping and indexing in code, you declare what you want in one line, and the engine figures out how.

The mental model — projections vs pipes (the one tricky bit)

A projection (created by [*], a slice, or []) makes the rest of the expression apply to every element. So members[*].name means “for each member, take .name”.

The catch: a projection keeps flowing rightward. members[*].age[0] tries [0] on each age (a number → null → dropped) and gives []. To index the whole result list, stop the projection with a pipe: members[*].age | [0] → the first age. Try both on the right — that one contrast explains half of JMESPath.
